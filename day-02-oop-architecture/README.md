# Day 2 - OOP, Collections and Application Architecture

## Overview

This project is a simple Java console application for managing bookings.

## OOP Concepts

- Class and Object
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction

## Java Collections

- ArrayList - stores multiple bookings
- HashSet - stores unique service names
- HashMap - retrieves a booking using booking ID

## Project Structure

- User.java
- Customer.java
- Service.java
- Booking.java
- Main.java
- architecture.md

## What I Learned

I learned how OOP concepts help organize Java code and how collections are used to store and retrieve multiple objects. I also understood how a console application can be connected to a frontend, backend, API and database in a real application.
